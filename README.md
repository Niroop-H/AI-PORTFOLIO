# Niroop H — AI Portfolio

A polished, responsive Next.js portfolio for Niroop H — Founder & CEO of MAH Quantum. Built with the Next.js App Router, React, TypeScript, and custom CSS.

## Local development

```bash
npm install
npm run dev
```

## Vercel deployment

Import `Niroop-H/AI-PORTFOLIO` into Vercel and keep the framework preset set to Next.js. Let Vercel manage the Next.js output directory.

## Notes

- Public-facing references link to the relevant organization or public record.
- Technology affiliations are represented as organizational ecosystem references, not personal certifications.
- Update the canonical URL in `app/layout.tsx`, `app/robots.ts`, and `app/sitemap.ts` after attaching your final custom domain.
